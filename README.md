# Jia-Xin Zhu — Personal website

A bilingual, responsive static website for GitHub Pages. No build step or dependencies.

- `index.html`: English homepage
- `zh.html`: Chinese homepage
- `cv-en.html` / `cv-zh.html`: printable CVs
- `style.css`: shared visual design
- `build_site.py`: bilingual source content and page generator; run Python to regenerate HTML after content edits.

## Deployment
Create `jxzhumark.github.io`, upload the five HTML/CSS/SVG assets and `.nojekyll`. In Settings → Pages, select Deploy from a branch, main, / (root).
